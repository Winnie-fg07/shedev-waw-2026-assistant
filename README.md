# AI Assistant Project (Google ADK Workshop)

This project is an AI-powered assistant built during a Google ADK (Agent Development Kit) workshop. The initial codebase was provided as a starter repository, and the goal of the workshop was to learn how to configure, run, and extend an AI agent system using real-world tools.

After cloning the repository, I worked through setting up the environment, running the application in Google Cloud Shell, and deploying the assistant using the ADK web interface. I also handled GitHub integration and project cleanup to make the repository publicly accessible and presentation-ready.

---

## Project Background

This project was developed as part of a hands-on AI workshop focused on building agent-based systems using Google’s Agent Development Kit (ADK). The starter repository provided the core architecture of the assistant, and participants were guided through setup and execution.

My role involved not only running the project but also understanding how the components work together and ensuring the system runs correctly in a cloud-based environment.

---

## What I Worked On

During this project, I was responsible for:

- Cloning and setting up the workshop repository in Google Cloud Shell
- Configuring the development environment for Python and ADK
- Running the AI assistant using the ADK web server
- Debugging setup and dependency issues during execution
- Managing Git and GitHub workflow (commit, push, authentication)
- Cleaning up repository files for clarity and presentation
- Publishing the project to a public GitHub repository for portfolio use

## Key Features

The AI assistant includes:

- Natural language question-answering capabilities
- Tool-based agent architecture using Google ADK
- Web-based interface powered by FastAPI
- Modular structure for integrating external tools and services
- Session-based interaction through a browser UI
